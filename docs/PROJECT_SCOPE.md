# Project scope

[← Portfolio](../README.md)

This portfolio contains four projects: Superstore Sales Analysis, Customer RFM Segmentation, Saudi Population Analysis, and Smart Task.

The three analytics projects are educational simulations developed with AI assistance. Their charts are rendered in Python from computed results. Power BI files are included, but Desktop refresh/render and Service publication have not been verified. No commercial impact is claimed.

Smart Task is a university front-end prototype. It uses manual priorities and local browser storage. Background notifications, automatic recurrence, AI ranking, and account synchronization are not implemented.

Sources, methods, and supporting results remain in each project folder.
