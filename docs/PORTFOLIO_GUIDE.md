## Start with the project story
Open any of the four project folders and read its README. The overview explains the question, work, and results before linking to the technical files.

## Simple project layout
Each analytics project shows only:
- **README.md** — the project story and navigation.
- **dashboard_preview.png** — the analysis preview.
- **implementation/** — all source data, code, queries, results, tests, and Power BI files.

Smart Task shows **README.md** and **app/**. Its pages, styles, and scripts stay together inside app so relative paths continue to work.

## Run an analytics project
Download the repository and open a terminal in the selected project's **implementation/** folder:

```bash
pip install -r requirements.txt
python analysis.py
python -m unittest discover -s tests
```

Open the generated dashboard.html locally. The preview generated by a new run is written inside implementation; the project-level image is the portfolio preview.

## Open Smart Task
Open smart-task/app/index.html locally. GitHub displays HTML source, not a running application.

## Power BI and scope
Follow implementation/powerbi/OPEN_IN_POWER_BI.md in the chosen project. Desktop refresh/render and Service publication remain unverified. Analytics work is educational and AI-assisted; see [project scope](PROJECT_SCOPE.md).
